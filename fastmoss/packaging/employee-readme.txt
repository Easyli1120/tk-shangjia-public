TK 上架助手 — Windows 安装使用说明
版本：2026.11.24

一、安装
1. 使用 Windows 10（1809 或更新）或 Windows 11，64 位 Intel / AMD 电脑。
2. 双击 TKShangjia-Setup-2026.11.24-x64.exe，按安装向导完成安装。
3. 点击桌面「TK 上架助手」，软件会启动本地服务并打开网页。

安装包内置 Python、程序依赖、采集浏览器，以及英文和简体中文 OCR 组件。
安装时不需要另外下载这些组件，也不需要安装 Python、Node 或数据库服务。
网页和教程中的 Redirect URL 固定为 http://127.0.0.1:8765/，每台电脑都使用此地址。
127.0.0.1 指当前电脑自身，不会连接到开发者或其他同事的电脑。
端口被占用或被系统限制时，软件会提示启动失败，不会自动换端口。请退出旧版软件或占用 8765 的程序后重试。
重复点击快捷方式会打开已经运行的服务。关闭浏览器页面后服务仍在后台运行。

二、首次使用
每台电脑从空白工作区开始。开发者的商品、图片、店铺授权和 AI 密钥不会随包分发。
进入「店铺管理」，按页面教程配置自己的店铺授权。
在 TikTok 的 Redirect URL 中完整填写 http://127.0.0.1:8765/，包括末尾斜杠。
授权浏览器和本软件必须运行在同一台电脑上，授权期间保持软件运行。
如果旧应用登记了其他本机端口，请在 TikTok 中保存新地址后重新授权。
地址一致不代表平台授权已完成；以实际返回软件并显示连接成功为准。若平台拒绝本地 HTTP 地址，需使用其认可的 HTTPS 回调方案。
需要使用 AI 图片功能时，在软件内配置自己的模型服务和密钥。
联网采集和店铺接口需要电脑可以访问对应网站；账号权限和人工验证码仍由使用者完成。
OCR 识别结果需要人工核对，不能保证所有花体、小字和遮挡文字都能识别。

三、数据保存
数据目录：%LOCALAPPDATA%\TKShangjia
此目录保存商品、图片、配置、日志和加密凭证。
卸载软件会保留数据；重新安装后可继续使用。
店铺凭证由 Windows 当前用户加密，复制到其他电脑不能代替重新授权。

四、安装文件说明
本版本未使用代码签名证书，Windows 可能显示未知发布者。
请只使用公司提供的安装文件，可用随附 SHA-256 文件核对完整性。
如启动失败，请检查数据目录中的 logs\desktop.log。
